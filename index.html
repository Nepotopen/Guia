Comandos Essenciais

git init

O comando git init é usado para inicializar um novo repositório Git em um diretório existente . Ele cria uma pasta oculta chamada .git, que contém todos os metadados necessários para o controle de versão.

git add .


Ele atualiza os arquivos de dentro da pasta

git commit -m "[Mensagem de Commit]"


Ele atualiza o repositório e deixa uma mensagem, geralmente de como estão as atualizações do projeto

git push -u origin main


Ele "empurra" as atualizações para o seu repositório, geralmente a origin é o github, mas isso foi previamente configurado

git fetch "[Mensagem de Commit]"


Verifica se o repositório remoto tem midificações em relação ao local

git Pull "[Mensagem de Commit]"


Ele puxa as atualizações que estavam remotas para o repositório local

git clone [link do repositório]


Ele trás todas as informações que está no repositório salvo online

git remote add origin[link do repositório]"


Conecta o repositório local ao repositório remoto

Dica: Importante digitar os comando corretamente respeitando os espaços entre as palavas e pontuações
